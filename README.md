# 🎓 Projeto Prático: O Mercado Tech Júnior

---

## 📌 Sobre o Projeto
Este site foi desenvolvido para a avaliação de **Front-end & Copilotagem com IA**. O objetivo é analisar a promessa dos bootcamps de "transição de carreira em 6 meses" e a realidade de saturação do mercado para desenvolvedores juniores.

O projeto inclui textos críticos, visualização de dados reais e uma ferramenta interativa de autoavaliação para os estudantes.

## 📂 Páginas e Recursos
* **`index.html`**: Página inicial com o resumo executivo e os pilares da crise de entrada no mercado.
* **`sobre.html`**: Análise crítica detalhada e impactos psicológicos.
* **`dados.html`**: Gráfico interativo demonstrando a demanda vs. formação (utilizando dados da Brasscom e INEP).
* **`teste.html`**: Questionário interativo (Diagnosticador) que avalia o perfil e os hábitos de estudo do usuário.
* **`fontes.html`**: Referências bibliográficas e transparência sobre o uso de IA (`AUDITORIA_IA.md`).

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Semântico)
* **CSS3** (Variáveis nativas e microinterações)
* **JavaScript Vanilla** (Lógica do teste e tema dinâmico)
* **Bootstrap 5** (Grid e componentes responsivos)
* **Chart.js** (Visualização de dados/Gráficos)
